The Spring team announces the release of Spring AI 2.0.0-RC1, a major milestone bringing new features and refinements to the Spring AI framework for building AI-powered Java applications. This release candidate includes updates to model integrations, vector store support, and the AI advisor API ahead of the 2.0.0 GA release.
